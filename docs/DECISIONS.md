## 2026-08-24（3日目標・自律実装）

- **距離減衰の基準距離**: SPEC 6.1「発射時距離」は発射時点で相手が未確定のため、実装は **発射位置→命中位置の弾の飛行距離** で判定。実質同じ挙動。差が出るのは相手が弾に向かって走った場合のみ（少し有利判定）。
- **中心ヒット判定**: 弾は1tickに約23unit進むため、「命中時点の距離」だと中心を通る弾でも中心判定にならない。**弾道（直線）と中心の垂直距離**で判定するよう変更（テスト「中心ヒットは1.5倍」で検出）。当たり判定自体は1tickの移動線分で行い、すり抜けを防止。
- **ガード中の被弾**: 三すくみ「射撃＞防御」を「ダメージ0・ゲージ-25」と解釈。ゲージ0で自動的にガード解除＋0.6秒ブレイク。ガードブレイク中は移動・射撃・防御不可。
- **ライフスティール**: Day1は全キャラ共通の「命中で与ダメ50%シールド回復」のみ。スピード型固有の「背面180度限定＋秒間キャップ12」はセイバー実装時（2週間目標）に扱う。
- **被ダメ倍率**: Day1は1.0（標準）。キャラ実装時に1.3/0.85/1.0へ。
- **撃破時スロー0.3秒**: ホストのシミュレーション速度を0.3倍にして実現（見た目だけでなく全員同期のスロー）。
- **中継サーバーのビルド**: tsc の NodeNext だと shared の相対importに拡張子が必要になるため、esbuild でバンドル（`--packages=external`）。
- **フィールド寸法**: 論理1280×720。「画面幅」の%はこの1280を基準。
- **練習モード**: 動作確認用に「的（動かないプレイヤー）」と1人で戦えるモードをタイトルに追加。SPECにはないが、非エンジニアの確認導線として有用なので残す（2週間目標のbot Lv1に吸収予定）。
- **ルームコードの文字**: 0/O/1/I を除いた英数字32種（口頭で伝えやすくするため）。

## 武器を左右クリックに統一（裁定10・ユーザー決定）
- 武器切替という操作を廃止。**左クリック＝主武器 / 右クリック＝副武器**の2枠に統一
  - スピード型: 左セイバー / 右ピストル
  - 重量型: 左HMG / 右ナイフ
  - 支援型: 左「狙撃/ヒール」融合枠 / 右ジャブ
- 支援型は武器3種で2ボタンに載らないため、狙撃とヒールを左クリックに融合。離したときの溜め時間で3分岐:
  - 単クリック（< 0.15秒）= ヒール
  - 0.15〜0.3秒 = 不発（溜めフェイントを維持するための区間・ユーザー案）
  - 0.3秒以上 = 狙撃（威力は溜め時間に比例。従来どおり連続スケール、段階制にはしない）
- 廃止に伴い `weaponSwitchSeconds` と切替クールダウン中の攻撃ロックを削除（「切替直後に攻撃が出ない」不具合の解消を兼ねる）
- キー設定から「武器切替」の行を削除
- 【Claude提案・不採用】ガードで溜めキャンセル → ユーザー案（単クリック分岐）の方が追加ルール不要で優れるため棄却

## 入力ラッチ方式（裁定11）
- 症状: スキル・武器切替が不発になることがある
- 原因: `JustDown` を毎フレーム読んで `inputs` を上書きしていたため、tickが走らないフレームで拾ったエッジが次フレームに踏み潰される。描画は144Hz等でも sim は60Hz固定なので、高リフレッシュレート環境ほど頻発。ゲスト側も送信60Hzで同じ取りこぼし
- 対処: 押した瞬間をラッチ（フラグ保持）し、**tick／送信が必ず1回消費してから消す**方式へ変更
- 【Claude提案・ユーザー承認】tickRateの144Hzへの引き上げは棄却。原因がレートではなく取りこぼしであること、ホスト権威型でホストPCの負荷が2.4倍になること、既存の裁定・テスト70本が60Hz前提であることが理由。60Hzでの遅延は最大16.7msで体感不能

## 世界スケール 2/3（裁定12・ユーザー決定）
- キャラ・武器リーチ・スキル範囲・静穏オーラ・弾サイズ・弾速・移動速度を**一律 2/3**に縮小。時間とダメージは不変
- フィールド寸法(1280×720)は据え置きのため、キャラ基準ではアリーナが1.5倍広くなる（横断: 速1.8秒/重3.0秒/支2.25秒）
- 間合いの関係（何キャラ分でリーチが届くか）は完全に据え置き＝戦い方は変わらない。「移動している時間の割合が増える」のが唯一の変化
- 実装: `balance.ts` の `WORLD_SCALE` 定数1箇所。`px()` / `ratio()` / `cross()` を通して適用しており、`1` に戻せば旧スケールへ即復帰できる
- 実プレイで散漫に感じた場合はフィールド側を縮める方向で調整する

## 近接を棒の掃き判定に（裁定13・ユーザー決定）
- 旧: 決められた時刻に扇全体が一瞬光る点判定
- 新: **キャラ中心から伸びた棒が扇を掃き、棒が横切った相手に当たる**。判定・見た目の両方を変更
- パス設計（中心を横切る時刻が旧仕様と一致するよう調整＝手触りを維持）:
  - セイバー: **2往復＝4パス**（各0.1秒）。中心通過 0.05/0.15/0.25/0.35秒＝旧hitTimesと完全一致。多段4ヒットを視覚化
  - ナイフ: 1パス（0.15〜0.45秒）。中心通過0.3秒＝旧hitTimeと一致
  - ジャブ: 1パス（0.03〜0.13秒）。中心通過0.08秒＝旧hitTimeと一致
- ダメージ量は不変（単発武器は扇内の相手をいずれ棒が通過するため）。変わるのは扇の端にいる相手に当たるタイミングのみ
- ジャブの扇を **0.7 → 1.0ラジアン**（片側40度→57度）に拡大。範囲が見やすくなる代わりに支援型の近距離自衛は強化側に動くので、実プレイで要観察
- マーク回収の「初撃」判定は、スイング全体の初撃から**相手ごとの初撃**へ変更（掃き方式に整合）

## ESCメニューと訓練場のリセット（裁定14・ユーザー決定）
- 常設の退出ボタンを廃止し、**ESCキーでメニュー**を開く方式に。退出の確認ステップは無し（ユーザー決定）
- メニュー表示中もゲームは止めない（オンラインで止められないため挙動を揃える）。開いている間は操作入力を無効化してクリックの誤爆を防ぐ
- 訓練場: リセット / ゲージ全快 / キー設定 / 閉じる / 訓練場から退出
- 対戦: 閉じる / マッチから退出
- **訓練場に経過時間の概念を持たせない**（HUDの時計を「訓練場」表示に置換）
- リセット = 訓練場に入り直したのと同じ状態。ゲージは**ゼロ**で戻す
- 「ゲージ全快」はリセットとは別項目として独立（ユーザー決定）。リセットと補給は目的が違う操作なので混ぜない
- 【Claude提案・不採用】リセットでゲージ全快 → 実戦のゲージ管理が練習できなくなるため棄却
