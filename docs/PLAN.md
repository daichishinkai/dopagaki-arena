## 確認手順（だいちがやる）
1. `npm install` → `npm run dev`
2. http://localhost:5173 を開く → 「練習（1人・的あり）」→ WASDで動く／マウスで向く／クリックで弾／的に当てるとHPバーと数字が出る／スペースで防御（輪郭が黄色く太くなる）
3. ブラウザをもう1枚（シークレット）開く → 片方「ルームを作る」→ コードをもう片方で「コードで参加」→ 両方のロビーに2人 → ホストの「開始」
4. 互いの動き・弾が見える／当てると相手のHPが減る／3回倒すとリザルト／「再戦」で2試合目
5. シークレット側を閉じる → 通常側で相手が消えて試合継続。逆にホスト側を閉じる → 相手はタイトルに戻る
